## Goal of the website
1. Rank on Google + AI answer engines (ChatGPT, Perplexity, Gemini, Claude) for job-search keywords — "Naukri profile optimization", "not getting calls from Naukri", "Naukri resume headline", "ATS friendly resume", etc.
2. Convert visitors → short form (name, mobile, email, Naukri link and/or resume link, experience, target role, optional message).
3. Every lead → saved in D1 + emailed to owner instantly.
Owner's instruction: *clean, simple, professional, call-to-action focused; don't add extra things.*

## Tech decisions (2026-11-19)
- Cloudflare **Workers + Static Assets** (hosting) + **D1** (lead DB) + **Email Routing send_email** (notifications). No paid services, no API keys.
- Static HTML generated by `build.mjs` (zero dependencies). Wrangler runs the build automatically on `dev` and `deploy`.
- `public/` is generated and git-ignored — never edit it by hand.
- CSS/JS URLs carry a content hash (`?v=…`) so the 1-year cache is safe.
- Brand colors from owner's palette image: Deep Forest `#0F3D3A`, Golden Hour `#F4B13B`, Terracotta Clay `#E0745E`, Warm Sand `#F2E6D6`.

## Content rules (keep following these)
- **No fake testimonials, ratings, review counts or client numbers.** Google penalizes fake reviews and it's legally risky. Add real testimonials only with the client's written permission (screenshots of WhatsApp messages with names blurred are fine as images; do not add `Review`/`AggregateRating` schema for self-written reviews).
- **Never promise a job or a fixed number of calls.** Wording used: "usually within a week", "many candidates…". Terms page has a no-guarantee clause.
- **Trademark disclaimer:** "Not affiliated with Naukri.com or Info Edge (India) Ltd." is in the footer and Terms. Keep it.
- No Naukri password is ever requested — this is a trust point used across the site.
- Guides should start with a "Quick answer" box and use question-style headings (good for AI answers).
